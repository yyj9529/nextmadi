## 3. 단계별 계획

순서는 기존 체크리스트와 같다. 앞 단계가 X면 아래로 내려가지 않는다. 서버 기동은 부수효과가 있으므로 오너 확인 후에만 한다.

### Phase 1: 정적 게이트 (자동, 서버 불필요)

```powershell
bun run typecheck
bun run lint
bun test
```

백엔드(Docker 기동 후):

```powershell
cd backend; ./gradlew spotlessApply spotlessCheck test build
```

통과 기준: 전부 0 실패. 백엔드는 skipped 개수를 기록한다(지난번 skipped 1은 OpenAI 키 필요 테스트). Testcontainers가 skip되면 통과로 치지 않는다.

### Phase 2: 환경 기동 (A 그룹)

- Postgres 5432, DB 이름 phraselog_dev, Flyway 마이그레이션 전부 success
- 백엔드 8080 health UP (local 프로파일)
- 프런트 `bun run dev` 포트 3000 고정(Google OAuth 콜백이 3000에만 등록). 라우트 전부 404면 `.next` 삭제 후 재시작
- INTERNAL_AUTH_SECRET: 기본 dev 시크릿이면 이제 기동이 거부되는 것이 정상(#176). 거부 동작을 직접 한 번 확인

### Phase 3: 화면 검증 (브라우저, 오너 또는 ui-verify)

수정 확인 5건을 먼저, 그다음 전체 회귀.

수정 재확인 5건:

| 코드 | 절차 | 기대 |
|---|---|---|
| T-CANCEL | /try에서 제출 직후 취소 클릭, 네트워크 탭 확인 | 요청이 cancelled로 표시, 즉시 재제출 가능 |
| T-NICK | 설정에서 공백 없는 100자 닉네임 저장. 375px에서도 | 말줄임 처리, 편집 버튼 보임. 빈 값/101자는 검증 에러 |
| T-LOGIN | 로그인 상태로 /login 직접 입력 | /home으로 리다이렉트 |
| T-REVIEW-ERR | 백엔드 중단 후 /review | 에러 안내 + 하단 네비 표시, 다른 탭으로 이동 가능 |
| T-375 | 375px에서 /library, 가능하면 실기기 | 검은 덮임 재현 여부. 재현되면 스크린샷 + will-change 영향 조사 |

전체 회귀(체크리스트 ID 그대로 재실행):

- B 마케팅: /, /terms, /privacy, 없는 경로, 비로그인 보호 경로 리다이렉트, 콘솔 에러 0
- C1 체험: 정상 입력, 짧은 문장, 평가 요청, 모호 입력(needs_context), 단어 하나, 비한국어, 500자 초과, 일일 한도 429, 타임아웃/502, 마이크 거부. C1-12 음성 입력은 오너 브라우저
- C2 로그인/온보딩: Google 로그인(포트 3000), Kakao는 키 없으면 N, 신규 사용자 코치 선택, 재로그인 시 온보딩 건너뜀
- C3 홈, C4 저장/라이브러리/상세, C5 복습(good/easy 간격도 DB로 확인: 지난번 hard만 확인), C7 설정(삭제 요청, 유예 중 재로그인 취소)
- C6 롤플레이: 세션 시작, 진행 표시, 텍스트 턴, 더블클릭 중복, 새로고침 복원. 진행 표시는 s12.md 기준으로 판정

### Phase 4: 롤플레이 결과 타임아웃 실측 (C6-06 / #177)

1. 백엔드 로그 레벨에서 새 스택 트레이스 로그가 나오는지 확인(이번 브랜치 변경)
2. 롤플레이 세션 3~5회 완주하며 `ai_request_logs`의 feature=roleplay_result 행의 latency, status, error_code 수집
3. error_code가 unknown인 이유: 스택 트레이스에서 SocketTimeoutException인지 확인. 타임아웃인데 unknown으로 찍히는 매핑 버그가 있으면 별도 수정
4. latency 분포(최소/중앙/최대)를 오너에게 보고하고 타임아웃 값은 오너가 결정
5. 풀린 뒤 C6-06, C6-07(재방문 시 재생성 안 함), C6-08(저장 멱등)을 이어서 검증

### Phase 5: 횡단 (D 그룹)

- D-01 세션 만료 시 화면 내 API 호출(분석 제출 등) 경로: 지난번 미확인이던 부분
- D-02 백엔드 중단, D-05 오프라인(오프라인 중 제출 시 입력 유지), D-09 새로고침/뒤로가기
- D-03, D-04 내부 인증: 헤더 없음/가짜 헤더 401, /actuator/health만 공개
- D-10 IDOR: 지난번 미확인 범위인 복습 submit, 롤플레이 턴/결과/저장, BFF 경로 추가
- D-11 XSS/이모지/초장문
- D-06/D-07 375px, 768px, 다크모드(다크모드는 미구현이 확정이라 "해당 없음"으로 기록)

### Phase 6: AI/데이터 (E 그룹)

- E-01 ai_request_logs 시도별 1행, E-02 스키마 검증 실패 1회 재시도, E-03 eval/runs 원문 없음
- 실제 Claude 호출은 S07 분석 1회 + 롤플레이 결과 1회만. 이슈 #107(키 있는 환경에서 S07 실호출 검증)과 겹치므로 같이 닫을 수 있다

## 4. 완료 기준

- 정의한 "알려진 제외"를 뺀 모든 항목이 O
- X는 재현 정보(화면, 입력, 기대와 실제)를 메모에 남기고 티켓화
- N은 사유(키/환경/종속) 명시
- 결과는 체크리스트 xlsx에 새 실행 열로 추가하고 dev-log 작성, 재발한 실수는 `docs/solutions/` 재발 이력에 한 줄
